# 2048 小游戏

经典 2048 网页版：滑动合并相同数字，冲向 2048！

- 🎮 在线游玩：<https://jie11122.github.io/2048/>
- 📱 手机滑动 / 键盘方向键（WASD 也可）
- ✨ 滑动与合并动画、分数与最高分本地保存、撤销一步、2048 胜利与游戏结束判定
- 🌐 单文件零依赖，加载后可离线游玩

## 本地运行

直接用浏览器打开 `index.html` 即可。

## 测试

```bash
node test-2048.mjs
```

自检覆盖：合并规则边界用例、四方向移动、随机棋盘不变量、动画轨迹一致性、随机完整对局与 UI 冒烟测试。
